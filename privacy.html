PROTOTYPE INFORMATION / 9 OCTOBER 2026

Privacy & data

This note describes the AirSight website and browser demonstration supplied with this project.

What runs in your browser

The prototype contains simulated air-quality, source, plot and workflow records. Interface changes such as selecting a ward or marking a mock review are kept in page memory and reset when you reload. Downloaded evidence records are generated locally and labelled as simulations.

Data collection

This version has no application database, visitor analytics, contact form, advertising trackers or calls to an AI API. Do not enter personal, confidential or operational case data into the demonstration. The hosting service may process access logs, IP addresses or authentication details under its own policies. A private review copy may require its hosting provider's sign-in.

External links

Links to GitHub and other services take you outside this website. Activity on those services is governed by their own terms and privacy policies. Use GitHub only for public, non-sensitive project discussion.

Prototype limits

All displayed forecasts, confidence values, performance metrics and impact estimates are illustrative. The demo is not a live monitoring system, validated scientific assessment, health service or operational enforcement tool. No dispatch, advisory or legal action is sent.

Future integrations

A live service would require defined data sources and permissions, access controls, retention rules and a revised privacy notice. Any proposed Claude workflow would be implemented server-side, use approved inputs and require human review.

For a public project question, visit the AirSight issue tracker.
