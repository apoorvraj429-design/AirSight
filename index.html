ABOUT THE PROJECT

Built around a practical question.

How can air-quality information become something a city team can investigate and act on?

AirSight is a project by Apoorv Raj exploring that question through a Delhi NCR decision-support prototype. It is intended for discussion with air-quality researchers, environmental teams and prospective pilot partners.

The present work demonstrates a product workflow. It does not establish real-world model accuracy, a government deployment or measured pollution reduction.

A FEW USEFUL DETAILS

Before you explore.

Is this real-time air-quality information?

No. The current demo uses synthetic values and historical-pattern scenarios. Numbers are examples, including model scores, response times, confidence intervals and impact estimates.

Does the demo use Claude today?

No. Claude is proposed for evidence-linked summaries and reviewable language outputs. Sensor ingestion, scientific modelling and a server-side Claude integration still need to be implemented and evaluated.

Is AirSight open source?

The repository is public. An open-source licence has not been selected, so no additional reuse rights are claimed here. You can inspect the code and discuss contributions through GitHub.

What happens when I click dispatch or verify?

Only the simulated interface changes. No external team is contacted and nothing is submitted to an authority. The evidence download is a local text record labelled as a simulation.

Does this website collect my data?

The application has no contact form, analytics or database and does not send data to an AI provider. The hosting platform may process access information. See the prototype privacy note.
