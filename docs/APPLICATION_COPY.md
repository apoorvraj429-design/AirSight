## Two-sentence project description

AirSight is an early-stage urban air-quality intelligence project with a working Delhi NCR simulation that demonstrates pollution monitoring, source context and field-review workflows. We plan to integrate Claude to turn verified environmental data into evidence-linked incident briefs and multilingual advisory drafts, with human review before any operational use.

## What are you building?

AirSight explores how city and environmental teams can move from air-quality signals to informed, reviewable action. The current browser-based prototype demonstrates a Delhi NCR command centre, ward-level source context, a stubble-risk workflow, a sample field-review queue and forecast/advisory views. It uses simulated data; live data ingestion, model validation and operational deployment are the next development stages. We intend to build a service that helps analysts organise approved evidence, understand uncertainty and prepare consistent briefings for human decision-makers.

## How will you use Claude?

We plan to use the Claude API for an evidence-linked briefing assistant. Given approved, timestamped environmental records, it would summarise changes, cite the underlying records, identify missing information and draft material for analyst review. A later phase could support questions over an approved evidence base and multilingual advisory drafts. Claude would assist with language and synthesis; pollutant calculations, forecasting, source modelling and data-quality checks would use separately validated methods. The current public prototype does not yet call the Claude API.

## Why do you need access or credits?

Access would help us implement and evaluate the first Claude-assisted briefing workflow: compare generated summaries against source records, measure citation completeness and unsupported claims, test latency and cost, and improve reviewability with user feedback. We would start with a small, clearly labelled demonstration dataset, then work toward a controlled pilot after securing data permissions and confirming user needs. We are seeking support for product development and evaluation, without treating the current simulation as a production deployment.
